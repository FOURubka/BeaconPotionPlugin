# BeaconPotionPlugin

Плагін для Minecraft 1.21.1 Purpur, який дозволяє налаштовувати маяки за допомогою вибухових зілля.

## Опис

Цей плагін додає можливість кидати вибухові зілля з ефектами на маяки, після чого маяк почне постійно давати цей ефект гравцям у радіусі дії, як звичайний маяк. Ефект зберігається до тих пір, поки маяк не буде зламано.

## Особливості

- 🎯 Кидайте вибухові зілля на маяк, щоб налаштувати його ефект
- 🔄 Маяк постійно дає ефект гравцям у радіусі дії
- 📏 Радіус дії залежить від рівня піраміди маяка (20-50 блоків)
- 💾 Ефекти маяків зберігаються між перезапусками сервера
- ✨ Візуальні ефекти при налаштуванні маяка
- 🔨 Ефект видаляється після зламу маяка

## Встановлення

1. Скомпілюйте плагін за допомогою Maven:
   ```bash
   mvn clean package
   ```

2. Скопіюйте файл `BeaconPotionPlugin-1.0.0.jar` з папки `target` в папку `plugins` вашого сервера Purpur

3. Перезапустіть сервер

## Використання

1. Створіть повноцінну піраміду маяка з блоків заліза, золота, діамантів, смарагдів або незериту
2. Встановіть маяк на вершині піраміди
3. Створіть вибухове зілля з бажаним ефектом
4. Киньте вибухове зілля на маяк або поблизу нього (в радіусі 3 блоків)
5. Маяк тепер буде давати цей ефект всім гравцям у радіусі дії!

## Підтримувані рівні піраміди

- **Рівень 1** (3×3): Радіус дії 20 блоків
- **Рівень 2** (5×5): Радіус дії 30 блоків
- **Рівень 3** (7×7): Радіус дії 40 блоків
- **Рівень 4** (9×9): Радіус дії 50 блоків

## Технічні деталі

- Ефекти перевіряються та накладаються кожну секунду
- Дані маяків зберігаються у файлі `plugins/BeaconPotionPlugin/beacons.yml`
- Плагін автоматично видаляє зламані маяки зі списку активних
- Підтримуються всі стандартні ефекти зілля Minecraft
